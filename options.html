DigestDock 1.4.2

DIGESTDOCK

使用你自己的 API 密钥

密钥仅保存在当前 Chrome 个人资料中。DeepSeek 用于 AI 功能，Supadata 是可选服务，用于为新的 YouTube 视频获取原生字幕。本开源扩展没有开发者服务器，也不使用分析服务。

服务连接

D

DeepSeek V4 Flash

概览、解释、翻译和笔记润色

未配置
必需

DigestDock 使用 DeepSeek V4 Flash 生成概览、解释内容、翻译字幕和润色笔记。 创建 DeepSeek API 密钥。

使用 AI 功能时，DeepSeek 会收到视频字幕及相关视频上下文。保存前请查看 DeepSeek 的服务条款和价格。
S

Supadata

新 YouTube 视频的可选字幕服务

未配置
可选

新的 YouTube 字幕由 Supadata 获取。它对整个扩展仍是可选配置，但只有你在侧边栏确认本次使用第三方 Supadata 时才会调用，且逐视频授权；B 站不会使用。 创建 Supadata 账号并获取密钥。Supadata 会在引导流程中生成密钥。

笔记备份

JSON 备份只包含已保存笔记、语言版本和经过校验的 YouTube 或 B 站媒体身份与时间戳，不包含 API 密钥、设置、完整字幕或摘要缓存。导入会重建安全时间戳链接，与本机笔记合并，并自动跳过重复项。

本地数据

摘要、翻译和笔记仅保存在当前 Chrome 个人资料中。你可以随时删除。

本地改造 想使用其他 AI 模型？ 编辑并复制一段可安全交给编程 Agent 的提示词 可交给编程 Agent

你可以直接编辑提示词。复制前完成以下三步：

  1. 在编程 Agent 中打开 DigestDock 解压后的项目文件夹。
  2. 把 [PROVIDER] 和 [MODEL] 替换成你想使用的服务和模型。
  3. 不要在提示词或聊天中加入 API 密钥。代码准备好后，请自行填写。
复制前，请先把 [PROVIDER] 和 [MODEL] 替换成你想使用的服务和模型。

隐私说明

DigestDock 没有开发者服务器，也不使用分析服务。API 密钥、缓存摘要、翻译和笔记只保存在当前 Chrome 个人资料中。

完整数据流说明请参阅仓库中的 PRIVACY.md。
